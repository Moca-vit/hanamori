# HANAMORI（ポートフォリオ用デモサイト）

花畑と森林浴をテーマにした、架空のバスケアブランドのWebサイトです。
HTML・CSS・JS のみで作成しています（フレームワーク・ビルド不要）。

## 見かた

VS Code でこのフォルダを開き、拡張機能「Live Server」をインストールして、右下の「Go Live」を押すと表示されます。
ファイルを保存するたびにブラウザが自動で更新されます。`index.html` をダブルクリックして開くこともできます。
（Google Fonts の読み込みにはインターネット接続が必要です）

## フォルダ構成

```
index.html              トップページ
html/                   下層ページ
  products/             商品一覧・香りごとの商品詳細
css/
  style.css             全ページ共通の読み込みファイル
  base/                 変数（色・フォント・余白）、リセット、文字
  layout/               ヘッダー、フッター、グリッド
  components/           ボタン、カード、フォーム、流れる帯、きらめき など
  pages/                ページ固有のスタイル（top / product / cart）
js/
  main.js               各モジュールの起動
  data/site.js          SNS の URL、メニュー、送料
  data/products.js      商品・価格・画像のデータ
  modules/              ヘッダー、演出、カート、フォーム など
assets/images/          仮画像（SVG）
```

## よく触る場所

| やりたいこと | 編集するファイル |
| --- | --- |
| 色・フォントを変える | `css/base/variables.css` |
| 商品や価格を変える | `js/data/products.js` |
| SNS の URL を本番に差し替える | `js/data/site.js` |
| メニューのリンクを増やす | `js/data/site.js` の `nav` / `footerNav` |
| OGP の URL を差し替える | 各 HTML の `og:url` / `og:image`（現在は example.com） |

## ページを追加するとき

1. 既存の下層ページ（例：`html/faq.html`）をコピーする
2. `<title>`・`description`・本文を書き換える
3. 必要ならメニューに追加（`js/data/site.js`）

ヘッダー・フッターは JS で自動的に差し込まれるため、各ページに書く必要はありません。
`<body data-root="../">` は、そのページからサイトのルートまでの相対パスです（階層に合わせる）。

## 演出

- ファーストビュー：コピーが1文字ずつ → 背景 → 額縁 → 商品の順に現れる。画像の読み込みを待ってから開始（最大2.5秒）
- 漂う光の粒、画像のパララックス、文字と写真が流れる帯、ホバーで文字がきらめく
- OS の「視差効果を減らす」設定がオンのときは、すべての動きを止める

## カート（デモ）

カートの中身はブラウザの localStorage に保存します。実際の決済・注文送信は行いません。
本番化する場合は `js/data/products.js` を Shopify や Stripe の商品データに差し替えます。

## 表現について

シャンプー・トリートメントは化粧品、入浴剤は医薬部外品として表記しています。
効能効果は一般的な薬用入浴剤の表示例で、架空のものです。
